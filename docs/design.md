# Criterio de presentación

**Qué es:** registro de ingresos por turno para un puesto de mollejitas.
**Para quién:** quien atiende el puesto y revisa sus ventas; clientes que exploran el portafolio.
**Objetivo:** registrar, editar y analizar un turno desde la primera pantalla.

Se conserva la identidad que el propietario pidió mantener. Color: ámbar `#b45309` (cabecera), naranja `#c2410c` (acento del puesto), blanco `#ffffff` (formulario), gris `#374151` (texto), verde `#047857` (importes), azul `#2563eb` (foco). Los tonos con texto blanco se oscurecieron para mejorar su contraste, conservando la misma familia de color. Tipografía: Poppins, regular para contenido y semibold para títulos y controles; fuentes locales.

Layout alineado a la izquierda: cabecera, resumen del día/mes, formulario junto al historial. En móvil se apilan y el análisis abre como un diálogo desplazable.

```text
Demo local · explicación                 Código
MolleVentas                   Copia / Análisis
Ayuda de registro             Restaurar / Ejemplo
[ Hoy ]            [ Mes ]          [ Registros ]
[ Formulario por turno ]      [ Historial filtrado ]
```

Principio rector: el puesto de comida mantiene su ámbar reconocible y el registro sigue siendo el centro del producto. La mejora aclara el significado de los datos sin convertir el proyecto en una plantilla de marketing. Se retiraron las animaciones continuas de cabecera y tarjetas para dar prioridad al uso.
